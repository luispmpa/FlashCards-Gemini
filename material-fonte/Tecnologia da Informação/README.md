# Tecnologia da Informação

Agrupa as matérias da área de **TI**. Cada subpasta é uma matéria (deck raiz);
coloque os PDFs de cada matéria na subpasta correspondente:

- Banco de dados
- Governança de TI
- Engenharia de Software
- Desenvolvimento de Software
- Informática
- Redes e Segurança
- Arquitetura de Computadores

O **nome da subpasta** é usado como a **matéria** ao organizar os flashcards; a
rotina identifica o assunto de cada PDF pelo **conteúdo** (não pelo nome do
arquivo) e marca cada flashcard com o tópico (campo `topicName`).
