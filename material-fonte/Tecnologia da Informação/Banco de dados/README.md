# Banco de dados

Coloque aqui os PDFs **desta matéria** (teoria + questões + gabarito).

- Cada PDF normalmente trata de **um assunto/tópico específico**.
- A rotina identifica o assunto pelo **conteúdo** do PDF (não pelo nome do
  arquivo, que pode ser aleatório) e marca cada flashcard com esse tópico
  (campo `topicName`).
- O **nome desta pasta** é usado como a **matéria** (deck raiz) ao organizar os
  flashcards.
